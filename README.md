# Pyxel RPG Test

Pyxelで制作中の、シンプルな2Dドット絵RPGです。  
フィールド探索、敵とのバトル、宝箱、ショップ、ダンジョン移動、レベルアップ、アイテム使用、魔法、HP/MPゲージ、UIウィンドウ、アイコン、バトルエフェクトなどを実装しています。

---

## 🎮 ゲーム概要

プレイヤーを操作してフィールドやダンジョンを探索し、敵を倒しながら成長していくRPGです。

現在の主な目的は、フィールド上にいるドラゴンを倒し、封印されたゴールへ到達することです。

### 主な流れ

1. フィールドを探索する
2. 宝箱やショップでアイテムを集める
3. 敵と戦って経験値・ゴールドを獲得する
4. レベルアップや装備入手で強化する
5. ドラゴンを倒す
6. ゴールへ到達してクリア

---

## 🧩 実装済み機能

### フィールド探索

- 20x15 の文字列マップによるフィールド管理
- 壁との当たり判定
- プレイヤー移動
- フィールドマップとダンジョンマップの切り替え
- 宝箱取得
- ショップ利用
- ゴール判定
- 安全地点への押し戻し処理

### バトル

- 敵との接触でバトル開始
- 通常攻撃

- 魔法攻撃
- 回復魔法
- 防御
- 逃走
- 敵の反撃
- 敵撃破後の報酬獲得
- 経験値・ゴールド獲得
- アイテムドロップ
- レベルアップ
- ゲームオーバー処理

### UI / 描画

- `.pyxres` による画像素材読み込み
- フィールドタイル描画
- プレイヤースプライト描画
- バトル用プレイヤー・敵スプライト描画
- UIウィンドウ枠描画
- HP / MP / ポーション / エーテル / ゴールド等のアイコン表示
- バトル中のHP/MPゲージ表示
- 敵HPゲージ表示
- 攻撃・魔法・回復・防御エフェクト表示
